# OpenMW

### Open-source reimplementation of the Morrowind engine

OpenMW is a free, open-source game engine that reimplements The Elder Scrolls III: Morrowind. Play the original game with modern enhancements — improved graphics, bug fixes, and powerful modding capabilities.

<br>

---

## Features

| | |
|:---|:---|
| **Modern Rendering** | Higher resolutions, better shadows, and improved visual quality |
| **Powerful Modding** | Extended scripting capabilities far beyond the original engine |
| **Bug Free** | Hundreds of engine-level bugs from the original game fixed |
| **Cross-Platform** | Runs on Windows, macOS, Linux, and even Android devices |
